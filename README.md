# MIZIZI — The Living Digital Atlas

MIZIZI is a cinematic digital platform beginning with Tanzania and designed to expand toward Africa and broader global exploration. It integrates culture, history, technology, and business discovery into a unified, high-performance experience.

## Project Structure
- `frontend/`: Next.js / React / TypeScript application
- `backend/`: Node.js / Express API
- `database/`: PostgreSQL / Prisma data layer
- `ai/`: Python / LLM / RAG agents
- `docs/`: Architecture & design notes
